Third-party material in the complete credential verification package

W3C context documents
This package includes context material from Verifiable Credentials Data Model
v2.0 (https://www.w3.org/ns/credentials/v2) and the Multikey context used by
Verifiable Credential Data Integrity
(https://www.w3.org/2025/credentials/vcdi/multikey/context/v1.jsonld).

and package-lock.json. Dependencies are installed by npm and retain their own
